# Reality ASM marketing

Content for Reality ASM and ASM Teach: reels, carousels, captions, calendars and launch posts.

Open a Claude Code chat on this repo and ask, for example:
- "Write 10 hooks for the Isotope Lab reel"
- "Plan the Instagram calendar for the beta (20 Oct to 4 Nov)"
- "Make a carousel about ASM Teach homework links"
- "Caption and hashtags for videos/isotope-lab-reel.mp4"

`BRAND.md` has the product facts; `CLAUDE.md` has the posting rules. Skills in `.claude/skills/` are from
[Ootto-AI/claude-content-skills](https://github.com/Ootto-AI/claude-content-skills) (MIT).
